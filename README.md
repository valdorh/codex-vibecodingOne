# Современный лендинг ТК "Промизоляция"

Одностраничный сайт с обновлённым дизайном под ключевые разделы: каталог, объекты, калькулятор, документы и контакты.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер, например:

```bash
python -m http.server 8000
```

Сайт адаптивен и поддерживает мобильное меню.
